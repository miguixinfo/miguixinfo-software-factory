# Documentación del proyecto

Aquí viven los artefactos de BMAD y el contrato de la API.

| Ruta | Contenido |
| --- | --- |
| `constitution.md` | Reglas no negociables del proyecto |
| `brief.md`, `prd.md`, `architecture.md` | Planificación BMAD |
| `epics/`, `stories/` | Epics e historias con criterios de aceptación |
| `api/openapi.json` | Contrato de la API, regenerado por los tests del backend |

Instala BMAD en el proyecto con `npx bmad-method install` y apunta su carpeta de salida a `docs/`.
